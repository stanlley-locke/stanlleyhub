# Week 01 Speaker Notes

## Tuesday notes
Emphasize that the bootcamp is not only about code. It is about workflow, discipline, and structured building.
Use simple project examples such as a student tracker or task manager.
Keep PM language beginner-friendly.

## Thursday notes
Slow down during Git and GitHub explanation.
Many beginners confuse local vs remote work.
Show commands clearly and repeat the purpose of each one.

## Saturday notes
Focus on reinforcement and confidence.
Do not turn the review into punishment.
Use student repos as examples of progress, not only mistakes.
