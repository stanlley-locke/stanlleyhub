# 04-slides

This folder contains the slide content and speaker notes for the StanlleyHub Software Bootcamp.

## Purpose
This folder organizes presentation materials for all live classes in the bootcamp.

## Structure
- `slides-map.md` — high-level map of all slide decks
- `slide-style-guide.md` — rules for how slides should be structured
- `00-shared/` — reusable slide templates and common visual notes
- `weeks/` — weekly slide content, grouped by Tuesday, Thursday, and Saturday sessions

## Weekly slide structure
Each week contains:
- `README.md` — summary of the week’s slide purpose
- `tuesday-slides.md` — concept session slide outline
- `thursday-slides.md` — workshop session slide outline
- `saturday-slides.md` — review/checkpoint/demo session slide outline
- `speaker-notes.md` — presenter guidance for all three sessions

## Slide principles
Slides should:
- support teaching, not replace teaching
- stay concise
- emphasize practical concepts
- highlight code/demo moments
- clearly separate concept, demo, and assignment moments
