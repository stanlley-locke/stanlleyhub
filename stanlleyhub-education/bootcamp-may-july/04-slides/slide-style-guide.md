# Slide Style Guide

## Purpose
This guide keeps all bootcamp slide decks consistent.

## Core rules
- one main idea per slide
- keep text short
- use slides to support explanation, not replace it
- include practical examples where possible
- use consistent slide ordering
- include assignment reminder near the end
- include recap at the start of each class

## Recommended slide order
1. Welcome / title slide
2. Session objective slide
3. Quick recap slide
4. Core concepts slides
5. Demo or example slides
6. Common mistakes or tips slide
7. In-class activity slide
8. Assignment slide
9. Closing / next class slide

## Recommended slide wording style
- simple
- direct
- practical
- beginner-friendly
- action-oriented

## Visual rules
- use clear headings
- avoid overloaded bullet lists
- keep code examples short
- use diagrams when a process is more important than syntax
