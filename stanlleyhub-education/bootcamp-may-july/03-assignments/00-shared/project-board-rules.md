# Project Board Rules

## Purpose
Project boards help track progress honestly and clearly.

## Minimum columns
- To Do
- In Progress
- Review
- Done

## Good board habits
- tasks should be specific
- tasks should be small enough to finish
- blocked tasks should be visible
- completed tasks should move to Done
- board should be updated regularly

## When a board is required
If a weekly assignment includes project tracking, the board link must be included in the submission.
