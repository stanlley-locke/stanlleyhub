# Naming Conventions

## Folder names
Use lowercase and hyphens where possible.

## Repo names
Use clear names such as:
- `week-02-portfolio-page`
- `week-03-js-counter-app`
- `week-06-express-api`
- `capstone-crm-system`

## File names
Keep names short and descriptive.

Good:
- `index.html`
- `style.css`
- `app.js`
- `README.md`

Avoid:
- `newfile.js`
- `myworkfinalreal.js`
- `stuff.py`
