# GitHub Submission Rules

## Every coding repo should include
- working source code
- README
- meaningful file names
- clean structure

## Commit rules
- commit regularly
- use meaningful commit messages
- do not make only one final commit unless unavoidable

## README minimum standard
A README should contain:
- project name
- summary
- features
- tech stack
- how to run or use
- future improvements if relevant

## Repo visibility
Use the repo visibility required by the instructor.

## Main quality rule
If you submit a repo, you should be able to explain what the code does.
