# Capstone Submission Requirements

## Final capstone must include
- GitHub repository
- README
- project summary
- features list
- project board or planning evidence
- final presentation/demo
- explanation of lessons learned

## Final capstone README should contain
- project title
- problem solved
- target users
- features
- tech stack
- how to run
- future improvements

## Final review expectation
Students should be able to explain:
- why they built the project
- what the MVP is
- what was completed
- what remains for future work
