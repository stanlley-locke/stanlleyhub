# Week 01 Main Assignment

## Title
Bootcamp Intro Repo and Project Board

## Objective
Set up the basic workflow that will be used throughout the bootcamp.

## Instructions

### Part 1 — Create your repository
Create a repository for this assignment.

Suggested name:
`week-01-bootcamp-intro`

### Part 2 — Create a README
Your README should include:
- your name
- why you joined the bootcamp
- what you want to learn
- what kind of project you want to build in the future

### Part 3 — Create a mini project scope
Choose one small project idea and define:
- project title
- problem it solves
- target user
- MVP features

### Part 4 — Create a project board
Create a simple board with at least these columns:
- To Do
- In Progress
- Done

Add at least 6 tasks for your mini project.

## Deliverables
- GitHub repo
- README
- mini scope document
- board link or screenshot

## Notes
This assignment is not about building a full app. It is about setting up your workflow correctly.
