# Week 02 Main Assignment

## Title
Portfolio Landing Page

## Objective
Build a simple personal portfolio landing page using HTML and CSS.

## Required sections
- hero section
- about section
- skills section
- contact section

## Required skills to show
- proper HTML structure
- semantic sections where possible
- basic CSS styling
- readable layout
- clean spacing

## Deliverables
- project repository
- README
- page source files

## Recommended file structure
- `index.html`
- `style.css`
- optional image assets folder

## Notes
This assignment should focus on clean structure and readability rather than complexity.
