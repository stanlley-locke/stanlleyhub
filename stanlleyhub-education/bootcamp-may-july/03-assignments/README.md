# 03-assignments

This folder contains all assignment materials for the StanlleyHub Software Bootcamp.

## Purpose
This folder is the home for all student tasks and project deliverables. It provides clear weekly assignment instructions, starter guidance, rubrics, examples, and submission rules.

## Structure
- `assignments-map.md` — high-level assignment overview
- `submission-guide.md` — how students should submit work
- `grading-overview.md` — how assignments are evaluated
- `00-shared/` — reusable rules, templates, and shared assignment resources
- `weeks/` — weekly assignment folders

## Weekly assignment folder pattern
Each weekly assignment folder contains:
- `README.md` — quick summary of the week’s assignment
- `assignment-xx-overview.md` — short summary and outcomes
- `assignment-xx-main.md` — full assignment instructions
- `starter-pack/` — templates, prompts, or idea packs
- `rubric.md` — evaluation criteria
- `submission.md` — exact submission instructions
- `examples.md` — examples of acceptable structure or quality

## Main assignment principles
- assignments should be practical
- assignments should build toward portfolio quality
- assignments should be submitted through GitHub whenever applicable
- students should document what they built
- students should update project boards when required
- students should be able to explain their work clearly
