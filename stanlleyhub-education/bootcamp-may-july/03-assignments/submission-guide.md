# Submission Guide

## General rule
All assignments must be submitted in the format requested for that week.

## Default coding assignment submission
Unless stated otherwise, coding assignments should include:
- GitHub repository link
- README
- screenshot or short demo description if needed
- project board link if required
- any required reflection notes

## GitHub rules
Students should:
- push all required files before the deadline
- make sure the repo link works
- make sure the README is updated
- make sure the code matches the assignment

## Classroom rules
If the assignment is posted in Google Classroom, the student should:
- submit the GitHub repo link
- attach any extra required files or reflections
- verify the submission is complete

## Late submission
Late submissions follow the bootcamp late-submission policy.

## Incomplete submission
A submission may be marked incomplete if:
- the repo link does not work
- the README is missing
- required files are missing
- the work clearly does not match the instructions
