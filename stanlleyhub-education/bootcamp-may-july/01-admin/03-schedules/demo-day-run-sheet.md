# Demo Day Run Sheet

## Purpose
Run the final presentation day smoothly and professionally.

## Before the session
- verify all student demo order
- verify links and project titles
- verify timing
- verify Meet access
- remind students of demo structure

## Demo structure per student/team
1. Introduce name and project
2. State the problem solved
3. Show key features
4. Explain stack used
5. Show GitHub repository
6. Share lesson learned
7. Share future improvements

## Timing
- 5 to 8 minutes demo
- 2 to 4 minutes Q&A

## After demos
- closing remarks
- recognition
- certificate timeline
- alumni/community next steps
