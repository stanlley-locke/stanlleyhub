# 01-admin

This folder contains the operational and administrative files required to run the StanlleyHub Software Bootcamp.

## Purpose
This folder is the control center for the bootcamp. It contains:
- program overview files
- policies
- onboarding materials
- schedules
- instructor guides
- lesson plans
- templates
- communication templates
- tracking files
- assessment rubrics
- certificate administration
- project management documentation
- support/troubleshooting
- post-bootcamp wrap-up files

## What should be stored here
Store only admin and operational files here.

Examples:
- policies
- attendance trackers
- welcome messages
- grading rubrics
- onboarding forms
- instructor checklists
- project management templates

## What should NOT be stored here
Do not store:
- raw teaching slides
- lesson source code
- student project code
- recordings
- curriculum code examples
- student-facing weekly coding materials

Those should live in:
- `02-curriculum/`
- `03-assignments/`
- `04-slides/`
- `05-recordings/`
- `06-projects/`

## Bootcamp summary
- Duration: 12 weeks
- Schedule: Tuesday, Thursday, Saturday
- Format: practical, live, project-based
- Main tools: WhatsApp, Google Classroom, Google Meet, GitHub, project tracking tools

## Folder structure
This folder is organized by function:
- `00-overview` — quick summary and master admin docs
- `01-policies` — rules and official policies
- `02-onboarding` — student setup and orientation
- `03-schedules` — dates, timetable, weekly release flow
- `04-instructor-guides` — teaching process and facilitation
- `05-lesson-plans` — weekly plans
- `06-templates` — reusable templates
- `07-communication` — post and message templates
- `08-tracking` — logs and trackers
- `09-assessment` — grading and rubrics
- `10-certificates` — certificate admin
- `11-project-management` — PM framework and templates
- `12-support` — troubleshooting and FAQs
- `13-post-bootcamp` — offboarding and improvements
