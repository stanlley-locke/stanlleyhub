# Weekly Structure

## Weekly flow

### Monday
- release weekly roadmap
- publish weekly materials in Google Classroom
- post weekly reminder in WhatsApp

### Tuesday
- concept class
- introduce new ideas
- teach fundamentals
- live demonstration

### Wednesday
- blocker check-in
- answer student questions
- remind students about Thursday workshop

### Thursday
- implementation class
- guided coding
- workshop
- debugging support
- assignment clarification

### Friday
- assignment progress check
- follow up with absent or struggling students
- remind students about Saturday review/checkpoint

### Saturday
- review and reinforcement
- code walkthroughs or demos
- project management check-in
- sprint planning
- capstone or project progress update

### Sunday
- upload missing recap materials
- update attendance and tracking files
- prepare next week

## Standard live class format
1. Attendance and warm-up
2. Concept teaching
3. Live demonstration
4. Guided practice
5. Questions and review
6. Assignment briefing
