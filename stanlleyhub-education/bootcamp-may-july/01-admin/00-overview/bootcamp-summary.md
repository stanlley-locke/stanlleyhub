# Bootcamp Summary

## Bootcamp name
StanlleyHub Software Bootcamp

## Duration
12 weeks

## Period
May to July

## Delivery model
Live, online, practical, project-based

## Schedule
- Tuesday
- Thursday
- Saturday

## Session duration
1 to 2 hours per class

## Teaching philosophy
This bootcamp is designed to be practical-first. Students will learn by building, debugging, documenting, presenting, and iterating on projects.

## Core tracks
1. Full-Stack Web Development
   - HTML
   - CSS
   - JavaScript
   - JS Frameworks
   - Node.js

2. Python Architecture
   - Python fundamentals
   - OOP
   - Flask
   - Django

3. AI/ML
   - LLM basics
   - prompt engineering
   - AI-assisted development
   - agentic AI concepts

4. DevOps and Infrastructure
   - Linux basics
   - Docker
   - deployment workflow
   - server and environment concepts

## Main tools
- WhatsApp
- Google Classroom
- Google Meet
- GitHub
- Trello / GitHub Projects / Notion
- Google Drive
- Google Forms
- Canva / Docs / Slides for certificates

## Expected student outcomes
By the end of the bootcamp, students should:
- understand software project workflow
- use Git and GitHub confidently at a beginner/intermediate level
- understand project management basics
- build front-end and back-end projects
- understand Python web development foundations
- understand database and authentication basics
- use AI tools responsibly in development workflows
- understand Linux, Docker, and deployment basics
- complete at least one capstone project
- leave with GitHub portfolio evidence

## Operating principles
- consistency over intensity
- practical learning over passive learning
- small weekly deliverables
- visible GitHub progress
- project management throughout the program
- strong communication and accountability
