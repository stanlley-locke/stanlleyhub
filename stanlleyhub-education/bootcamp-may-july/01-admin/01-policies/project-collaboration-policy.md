# Project Collaboration Policy

## Purpose
Students should collaborate honestly and professionally.

## Solo work
If an assignment is marked as solo:
- students may discuss ideas
- students may not submit copied work

## Pair or team work
If an assignment is collaborative:
- responsibilities should be shared clearly
- all contributors should understand the submitted work
- project boards should reflect actual progress

## GitHub workflow expectation
Collaborative projects should use:
- meaningful commits
- branches where applicable
- pull requests where applicable
- shared project documentation

## Accountability
Every team member should be able to explain:
- what the project does
- what they contributed
- what challenges the team faced
