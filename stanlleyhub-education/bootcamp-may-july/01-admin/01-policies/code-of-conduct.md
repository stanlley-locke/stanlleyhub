# Code of Conduct

## Purpose
This bootcamp is a professional learning space built on respect, discipline, and collaboration.

## Expected behavior
Students and instructors should:
- treat one another with respect
- communicate professionally
- support peers constructively
- be honest about progress and challenges
- ask questions without mocking others
- give feedback respectfully

## Unacceptable behavior
This includes but is not limited to:
- harassment
- insults
- discrimination
- bullying
- spamming groups
- repeated disruptive behavior
- plagiarism without acknowledgment

## Enforcement
Violations may lead to:
- warning
- restricted participation
- removal from certificate eligibility
- removal from the bootcamp in serious cases
