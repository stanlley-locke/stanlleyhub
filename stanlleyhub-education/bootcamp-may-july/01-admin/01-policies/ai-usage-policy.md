# AI Usage Policy

## Purpose
AI tools can support learning, but they must not replace understanding.

## Allowed use
Students may use AI tools for:
- explanations
- debugging support
- brainstorming
- documentation drafts
- improving clarity of code or comments

## Not allowed
Students should not:
- submit AI-generated code they cannot explain
- use AI to bypass learning entirely
- present copied AI output as their own understanding

## Instructor expectation
If a student uses AI-generated code, they must be able to:
- explain what it does
- explain how it works
- explain why they used it
- explain where it may fail

## Core rule
Understanding is required. Blind copy-paste is not acceptable.
