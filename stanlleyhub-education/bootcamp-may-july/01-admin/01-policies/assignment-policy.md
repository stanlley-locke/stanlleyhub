# Assignment Policy

## Purpose
Assignments are required to convert live instruction into practical skill.

## General rule
Every week contains at least one practical assignment.

## Submission method
Assignments must be submitted through the approved channel for that week, usually:
- GitHub repository link
- Google Classroom submission
- screenshot or demo link
- project board update

## Required elements for coding assignments
Where relevant, each coding assignment should include:
- GitHub repo link
- working code
- README
- short explanation of what was built
- updated project board if applicable

## Completion expectation
Students are expected to submit at least 80% of all assignments to remain eligible for certification.

## Quality expectation
Assignments should reflect the student’s actual understanding and effort. Copying without understanding is not acceptable.

## Review
Assignments may be reviewed through:
- instructor review
- peer review
- live checkpoint
- rubric-based scoring
