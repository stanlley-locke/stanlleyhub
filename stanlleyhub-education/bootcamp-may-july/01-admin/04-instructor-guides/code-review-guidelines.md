# Code Review Guidelines

## Purpose
Code review helps students improve readability, logic, and structure.

## What to review
- correctness
- clarity
- naming
- structure
- comments where needed
- README quality
- GitHub hygiene

## Review tone
- respectful
- specific
- constructive
- improvement-focused

## Good feedback examples
- This function works, but the name could be clearer.
- Consider splitting this into smaller functions.
- Your README is good; add setup instructions.
