# Class Delivery Framework

## Default class structure
1. Attendance and warm-up
2. Recap of previous lesson
3. Main topic explanation
4. Live demo
5. Guided practice
6. Questions and troubleshooting
7. Assignment briefing

## Delivery goals
Each class should:
- teach one clear concept or cluster of related concepts
- include a practical demonstration
- include learner action
- end with a clear next step
