# Pair Programming Guidelines

## Purpose
Pair programming builds collaboration, communication, and problem-solving habits.

## Roles
- Driver: types and implements
- Navigator: reviews, guides, and thinks ahead

## Rules
- switch roles regularly
- communicate clearly
- explain your thinking
- do not dominate the session
- both students should understand the code

## Good practice
- ask before changing direction
- pause to explain logic
- commit shared progress clearly
