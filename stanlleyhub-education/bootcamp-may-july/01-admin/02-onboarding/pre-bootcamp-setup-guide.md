# Pre-Bootcamp Setup Guide

Before the bootcamp begins, complete the following:

## Accounts
- GitHub
- Google account
- WhatsApp
- Google Classroom access

## Software
- VS Code
- Git
- Node.js
- Python
- Chrome or another modern browser

## Access checks
- can join Google Meet
- can open Google Classroom
- can push to GitHub
- can receive WhatsApp updates

## Mindset
Come prepared to:
- ask questions
- build every week
- submit work on time
- work consistently
- improve through practice
