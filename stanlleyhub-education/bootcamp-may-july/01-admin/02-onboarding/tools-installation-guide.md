# Tools Installation Guide

## 1. VS Code
Download and install Visual Studio Code from the official site.

## 2. Git
Download and install Git.
After installation, test in terminal:
`git --version`

## 3. GitHub
Create a GitHub account.
Set up a basic profile and keep your login details safe.

## 4. Node.js
Install Node.js.
Test:
`node -v`
`npm -v`

## 5. Python
Install Python.
During installation, make sure Python is added to PATH if required.
Test:
`python --version`

## 6. Browser
Use a modern browser such as Chrome.

## 7. Google Classroom
Join the bootcamp class and verify you can open posts, assignments, and links.

## 8. Google Meet
Test your microphone, speaker, and internet connection before orientation.

## 9. Optional productivity tools
- Trello
- Notion
- GitHub Projects
