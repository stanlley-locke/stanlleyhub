# Curriculum Map

## Bootcamp duration
12 weeks

## Schedule
- Tuesday
- Thursday
- Saturday

## Weekly structure
Every week includes:
- 1 concept lesson
- 1 workshop / implementation session
- 1 review / checkpoint / demo session
- 1 assignment
- GitHub submission
- project board update where required

## Weekly roadmap

### Week 1
Orientation, project management, Git, GitHub, developer workflow

### Week 2
HTML, CSS, web page structure, responsive design basics

### Week 3
JavaScript fundamentals: variables, functions, logic, loops, DOM basics

### Week 4
Advanced JavaScript, forms, debugging, local storage, GitHub collaboration

### Week 5
React fundamentals: components, props, state, events

### Week 6
Node.js, Express, APIs, CRUD, backend basics

### Week 7
Python fundamentals and OOP

### Week 8
Flask and Django basics

### Week 9
Databases, data modeling, authentication, architecture

### Week 10
AI/ML, LLMs, prompting, AI-assisted development, agentic AI concepts

### Week 11
Linux, Docker, deployment, DevOps basics

### Week 12
Capstone completion, demo preparation, demo day, graduation

## Project progression
- early weeks: mini projects
- middle weeks: framework/backend projects
- later weeks: architecture and capstone
- final week: polished capstone demo
