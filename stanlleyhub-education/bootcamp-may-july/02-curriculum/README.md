# 02-curriculum

This folder contains the student-facing and teaching-facing curriculum materials for the StanlleyHub Software Bootcamp.

## Purpose
This folder is the main content repository for the 12-week bootcamp. It is organized by week so that all teaching materials are easy to find, update, and reuse.

## Structure
- `curriculum-map.md` — high-level curriculum overview
- `course-structure.json` — structured course metadata for navigation and future automation
- `00-shared/` — reference materials used across multiple weeks
- `weeks/` — weekly folders, one folder per bootcamp week

## Weekly file pattern
Each week contains:
- `README.md` — quick summary of the week
- `overview.md` — weekly goals, concepts, outcomes
- `tuesday.md` — concept lesson notes
- `thursday.md` — workshop / implementation notes
- `saturday.md` — review / checkpoint / demo notes
- `assignment.md` — weekly assignment details
- `resources.md` — tools, reading links, references, support materials

## Delivery rhythm
This curriculum is designed around:
- Tuesday = concept and foundations
- Thursday = guided build/workshop
- Saturday = review, demos, sprint planning

## Core tracks
The bootcamp covers:
- Full-Stack Web Development
- Python Architecture
- AI/ML and Agentic AI
- DevOps and Infrastructure

## Core teaching principles
- practical first
- small weekly deliverables
- visible GitHub progress
- project management throughout
- strong documentation habits
- consistent repetition and review
