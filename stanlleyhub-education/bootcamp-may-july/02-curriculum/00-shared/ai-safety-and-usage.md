# AI Safety and Usage

## AI can help with
- explanation
- debugging support
- documentation
- brainstorming
- refactoring suggestions

## AI should not replace
- understanding
- logic
- testing
- ownership of your code

## Core rule
If you use AI-generated code, you must be able to explain it clearly.

## Risks to remember
- hallucination
- wrong logic
- insecure patterns
- overconfidence in generated output

## Safe practice
- verify every important result
- test code
- compare outputs
- ask why, not only what
