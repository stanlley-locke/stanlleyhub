# Tools and Workflow

## Main tools used in this bootcamp
- WhatsApp
- Google Classroom
- Google Meet
- GitHub
- Trello / GitHub Projects / Notion
- VS Code
- Node.js
- Python

## Main workflow
1. Read weekly materials
2. Attend Tuesday class
3. Build during Thursday workshop
4. Review and demo on Saturday
5. Submit assignment
6. Push work to GitHub
7. Update project board

## Submission rule
All coding work should be visible in GitHub unless the assignment instructions state otherwise.

## Communication rule
- use WhatsApp for quick updates and reminders
- use Classroom for official assignment details
- use GitHub for code
