# GitHub Workflow

## Standard workflow
1. Create or open your project folder
2. Initialize or clone repository
3. Make changes
4. Check status
5. Add files
6. Commit changes
7. Push to GitHub

## Good habits
- commit often
- use clear commit messages
- keep README updated
- organize files clearly
- create branches when working on separate features

## Basic commands
- `git init`
- `git status`
- `git add .`
- `git commit -m "message"`
- `git push`

## Required repo files where relevant
- source files
- README
- any setup notes
- screenshots if required
