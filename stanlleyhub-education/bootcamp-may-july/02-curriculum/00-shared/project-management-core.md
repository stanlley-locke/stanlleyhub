# Project Management Core

## Why project management matters
Good projects are not built by coding randomly. They are built by:
- defining the problem
- defining the MVP
- breaking work into tasks
- tracking progress
- reviewing frequently

## Core PM concepts
- Problem
- Scope
- MVP
- Backlog
- Sprint
- Task
- Blocker
- Review
- Retrospective

## Weekly PM ritual
Every Saturday, answer:
1. What did I complete?
2. What is still pending?
3. What blocked me?
4. What is my next sprint goal?
