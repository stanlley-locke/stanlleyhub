# Glossary

## API
Application Programming Interface. A way for software systems to communicate.

## Backend
The server-side part of an application that handles logic, data, and processing.

## Branch
A separate line of work in Git used for making changes safely.

## Commit
A saved checkpoint in Git history.

## CRUD
Create, Read, Update, Delete.

## DOM
Document Object Model. The structure of a web page that JavaScript can interact with.

## Framework
A structured set of tools and patterns used to build applications.

## Git
A version control system for tracking changes in code.

## GitHub
A platform for hosting repositories and collaborating on code.

## LLM
Large Language Model. A type of AI model trained on large amounts of text.

## MVP
Minimum Viable Product. The smallest version of a product that solves the main user problem.

## OOP
Object-Oriented Programming. A way of organizing code around classes and objects.

## Repository
A project folder tracked by Git.

## Sprint
A short focused work cycle used in project management.
