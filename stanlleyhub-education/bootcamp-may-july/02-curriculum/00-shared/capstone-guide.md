# Capstone Guide

## Purpose
The capstone is the final project that shows what you can build using the skills from the bootcamp.

## Capstone should include
- a clear problem
- a target user
- an MVP
- a GitHub repository
- documentation
- a final presentation

## Suggested capstone ideas
- CRM system
- e-commerce app
- inventory system
- student management app
- booking app
- AI assistant tool

## Capstone phases
1. Idea selection
2. MVP definition
3. Project board setup
4. Build
5. Review
6. Demo
