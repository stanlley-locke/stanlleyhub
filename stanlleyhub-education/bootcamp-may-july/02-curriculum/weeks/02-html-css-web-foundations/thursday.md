# Week 02 — Thursday

## Topic
CSS foundations

## Learning objectives
Students should be able to:
- write CSS syntax
- use selectors
- style text and layout
- understand the box model
- use simple flexbox

## Main notes

### CSS purpose
CSS styles the structure built with HTML.

### CSS syntax
selector + property + value

### Common selectors
- tag
- class
- ID

### Important properties
- color
- background-color
- font-size
- margin
- padding
- border
- width
- height

### Box model
- content
- padding
- border
- margin

### Layout basics
- `display`
- `flex`
- `justify-content`
- `align-items`

## In-class activity
Style the portfolio page.

## Exit task
Add styling for layout, colors, spacing, and typography.
