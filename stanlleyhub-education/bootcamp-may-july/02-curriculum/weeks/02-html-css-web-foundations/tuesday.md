# Week 02 — Tuesday

## Topic
HTML foundations

## Learning objectives
Students should be able to:
- explain what HTML is
- explain a basic HTML document structure
- use common HTML tags correctly
- understand semantic HTML

## Main notes

### What is HTML?
HTML is the structure of a webpage.

### Basic document structure
- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<body>`

### Common tags
- headings
- paragraphs
- links
- images
- lists
- forms
- buttons
- sections

### Semantic HTML
Use meaningful elements such as:
- `header`
- `main`
- `section`
- `footer`

## In-class activity
Create the structure for a portfolio page.

## Exit task
Build the page structure for:
- hero
- about
- skills
- contact
