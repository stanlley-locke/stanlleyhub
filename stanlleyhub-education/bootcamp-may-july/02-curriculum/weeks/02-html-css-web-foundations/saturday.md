# Week 02 — Saturday

## Topic
Responsive polish and review

## Learning objectives
Students should be able to:
- improve readability
- improve spacing
- improve layout for smaller screens
- explain how their page is structured

## Main notes

### Responsive thinking
Pages should remain readable on different screen sizes.

### Review questions
- Is the page easy to read?
- Is spacing balanced?
- Are sections clearly separated?
- Does the layout break on smaller widths?
