# Week 01 — Saturday

## Topic
Developer workflow practice

## Learning objectives
Students should be able to:
- combine PM and GitHub workflow
- create and update a board
- create a simple documented repo
- submit links properly

## Main notes

### Basic developer workflow
1. Understand the task
2. Define MVP
3. Break into tasks
4. Create repo
5. Write files
6. Commit progress
7. Push work
8. Update board
9. Submit work

### Good beginner habits
- commit often
- use clear filenames
- update README
- ask questions early
- keep board honest
- document progress

## In-class activity
Students finalize:
- intro repo
- README
- project board
- project scope

## Exit task
Submit:
- repo link
- board link
- README
