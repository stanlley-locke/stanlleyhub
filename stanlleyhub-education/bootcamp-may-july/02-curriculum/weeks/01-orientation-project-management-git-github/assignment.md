# Week 01 Assignment

## Title
Bootcamp Intro Repo and Project Board

## Objective
Set up the core workflow used throughout the bootcamp.

## Requirements
Create and submit:
1. A GitHub repository
2. A README with your goals
3. A mini project scope
4. A project board with at least 6 tasks

## Submission
- GitHub repo link
- project board link

## Success criteria
- repo exists
- README is clear
- tasks are meaningful
- student can explain MVP
