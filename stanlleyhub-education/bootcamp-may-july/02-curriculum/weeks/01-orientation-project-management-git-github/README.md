# Week 01 — Orientation, Project Management, Git, GitHub

## Theme
Getting started as a practical software learner.

## Focus
This week introduces:
- bootcamp expectations
- software project thinking
- project management basics
- terminal basics
- Git
- GitHub
- first repository setup

## Outcome
By the end of this week, students should:
- understand how the bootcamp works
- define a simple MVP
- create a basic project board
- create and push their first GitHub repository
