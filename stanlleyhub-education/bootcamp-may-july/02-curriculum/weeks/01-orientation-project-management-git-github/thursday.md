# Week 01 — Thursday

## Topic
Terminal, Git, and GitHub basics

## Learning objectives
Students should be able to:
- use simple terminal commands
- explain what version control is
- explain the difference between Git and GitHub
- create a repo
- commit and push files

## Main notes

### Why terminal matters
Developers use the terminal for:
- navigating projects
- running tools
- using Git
- backend workflows

### Basic terminal commands
- `pwd`
- `ls`
- `cd`
- `mkdir`
- `touch`

### What is version control?
A way of tracking changes in code over time.

### What is Git?
A tool for version control on your local machine.

### What is GitHub?
A cloud platform for storing repositories and collaborating on code.

### What is a repository?
A project folder tracked with Git.

### What is a commit?
A saved checkpoint in your project history.

### Basic Git flow
- `git init`
- `git status`
- `git add .`
- `git commit -m "message"`
- `git push`

### README purpose
A README should explain:
- what the project is
- what it does
- what tools were used
- how to run or view it

## In-class activity
Create first repository and push to GitHub.

## Exit task
Push one repository with a README.
