# Week 01 — Tuesday

## Topic
Introduction to software engineering and project management

## Learning objectives
By the end of this class, students should be able to:
- explain what software engineering is
- explain what a software project is
- explain the software lifecycle
- define MVP
- define backlog, sprint, and task
- create a basic task board

## Main notes

### What is software engineering?
Software engineering is the process of solving real problems using software.
It includes:
- understanding the problem
- planning the solution
- building the solution
- testing
- improving
- maintaining

### What is a software project?
A software project is an organized effort to build a digital solution.

### Project vs product
- Project = work being done
- Product = final system users interact with

### Software lifecycle
1. Problem identification
2. Requirement gathering
3. Planning
4. Design
5. Development
6. Testing
7. Deployment
8. Maintenance

### MVP
MVP = Minimum Viable Product.
The smallest version of a solution that still solves the main user problem.

### Project management basics
Important terms:
- scope
- backlog
- sprint
- task
- milestone
- blocker
- review
- retrospective

### Kanban
Basic columns:
- To Do
- In Progress
- Review
- Done

## In-class activity
Create a simple task board for a mini app idea.

## Exit task
Write:
- project title
- problem being solved
- MVP features
- 6 to 10 tasks
